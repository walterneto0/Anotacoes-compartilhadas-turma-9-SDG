Tutorial Required
  1. Run docker run -it -m 8g -p 8080:8080 liferay/portal:7.4.3.132-ga132
  2. In order to call Liferay REST services from this page, you will need to enable CORS. You can enable CORS in Liferay by navigating to the Control Panel > System Settings > Security Tools > Portal Cross-Origin Resource Sharing (CORS).
  3. Add new configuration entry. Make sure it includes a URL pattern /o/headless-delivery/* since the REST services we are calling are included in this path. Save your configuration.
